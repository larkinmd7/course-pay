# Course Pay

Минимальная статическая страница оплаты онлайн-программы «ИИ для экспертов».

## Проверка

```bash
node --test tests/site.test.mjs
python3 -m http.server 4173 --bind 127.0.0.1
```

В production сайт собирается из `Dockerfile` и обслуживается через
Dockploy/Traefik на `https://pay.larkinmd7.ru`.

У каждого тарифа есть собственная статическая success-страница. Она не
проверяет факт платежа и открывается любому, поэтому приглашений в чаты курса
на ней нет: доступ в чат выдаёт менеджер после подтверждения оплаты, контакт –
Telegram @starsevast. С 3 сентября 2026 оплата идёт по ссылкам ЮKassa
ИП Севастьянова, и они не возвращают покупателя на эти страницы.

Клики по кнопкам «Оплатить» на главной отправляют в Метрику `101476340` цели
`pay_tariff_start_click`, `pay_tariff_middle_click`, `pay_tariff_advanced_click`;
на `/tg/` – прежние `tg_tariff_*_click`.

## Самостоятельная работа с сайтом

Матвей (`msevastanov1307-star`) приглашён с правом записи только в этот
репозиторий. После принятия приглашения он может менять сайт и публиковать
без подтверждения Михаила.

1. Склонировать `https://github.com/larkinmd7/course-pay.git`.
2. Внести изменения и посмотреть локально: `python3 -m http.server 4173`.
3. Проверить: `node --test tests/*.test.mjs`.
4. Commit и push в `main` автоматически запускают сборку существующего
   приложения Course Pay в Dokploy. Другие ветки не публикуются.
5. Проверить `https://pay.larkinmd7.ru/` после сборки и мобильную версию.

Изменения в `main` сразу публикуются на боевом сайте. Доступ к SSH,
административной панели, DNS и остальным сайтам для этого не требуется.
Секреты и персональные данные в публичный репозиторий не добавлять.
Откат: revert нужного коммита и push в `main`.
